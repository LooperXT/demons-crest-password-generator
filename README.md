# Demon's Crest Password Generator

This project provides a static web page that generates passwords for Demon's Crest (SNES). The web page is designed to support screen readers and high-contrast displays.

## Usage

Select your key items and/or game mode, and click "Generate". The password generator will select the password that requires the fewest button presses to input.

## Notes

"Bosses-Only Mode" refers to a special setting that prevents common enemies from spawning, but also limits play to the early Stages of the game. Only one of the game's four endings can be earned when playing the bosses-only mode. Most users will want it to be toggled off. I have included a "Select All (Normal Mode)" button that toggles on all key items, but leaves this mode disabled.
